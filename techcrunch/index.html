Nvidia launches new platform for reining in rogue AI agents

Nvidia launched the Open Agent Safety Platform to address recent AI agent security breaches.

  • The platform combines OpenShell, an open-source software for controlling agent access, with Sentry, a monitoring system running on Nvidia BlueField-4 DPUs.

  • Dozens of companies, including Anthropic, Arm, Microsoft, Oracle, and SpaceX, have signed on to support the platform, while OpenAI is not currently listed as a participant.
