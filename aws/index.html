Automated web insight extraction with Amazon Bedrock AgentCore

  • Amazon Bedrock AgentCore Browser provides a fully managed browser service that reliably renders JavaScript-heavy web pages, overcoming issues with traditional web scrapers.
  • The solution uses an event-driven architecture with Amazon S3, Amazon SQS, and AWS Lambda to collect web content from RSS feeds, extract insights using Amazon Bedrock, and index the results for search.
  • AI-powered analysis with Amazon Bedrock extracts summaries, themes, entities, and actionable insights from web content, and generates vector embeddings for semantic search in Amazon OpenSearch Serverless.
  • URL hashing in Amazon S3 is critical for deduplication to manage costs associated with using AgentCore Browser sessions, which are more expensive than standard HTTP requests.

Introducing Web Search on Amazon Bedrock for foundation model grounding

  • Amazon Bedrock now includes Web Search, a server-side tool for grounding model responses in current web knowledge, eliminating the need for third-party web search integrations.
  • Web Search utilizes a multi-source grounding approach, combining a web index with a knowledge graph for factual accuracy and efficient retrieval using semantic snippet extraction.
  • Enabling Web Search is done through a single parameter in the OpenAI Responses API, requiring no vendor onboarding, API keys, or SDKs, and supports zero data egress by default.
  • Web Search is integrated with AWS CloudTrail for auditing, logging InvokeSearch and InvokeFetch calls without exposing query text, and is currently available in US regions (us-east-1, us-east-2, us-west-2).

Automated Reasoning policy refinement in Amazon Bedrock

  • Amazon Bedrock now offers automatic policy refinement to automate the process of diagnosing and fixing issues in Automated Reasoning policies, reducing manual effort.
  • Two new refinement modes are available: Iterative Refinement addresses rule issues by proposing edits to formal logic, while Ambiguous Variable Refinement resolves language issues by suggesting clearer variable descriptions.
  • Iterative Refinement requires a source document and optional feedback, analyzing divergence from the document to propose rule or variable changes, and uses an asynchronous API workflow (start, poll, retrieve).
  • Ambiguous Variable Refinement identifies overlapping or incomplete variable definitions causing translation issues and proposes refined descriptions, utilizing the same API workflow as Iterative Refinement but without the need for a source document or tests.

From weeks to minutes: How Formula 1® uses agentic AI on AWS to accelerate data operations

Formula 1® partnered with AWS to build the Data Accelerator, leveraging agentic AI to accelerate their MarTech data platform operations.

  • The Data Accelerator utilizes Amazon Bedrock AgentCore to reduce data source onboarding from 6-8 weeks to approximately 40 minutes of code generation plus deployment time.
  • The solution includes automated schema evolution detection and remediation, utilizing AWS Lambda and Amazon EventBridge to monitor for upstream changes and generate code updates.
  • A unified data access layer is built on Amazon SageMaker Unified Studio, enabling governed self-service data access for data scientists and analysts.
  • End-to-end observability and root cause analysis are provided through a new dashboard leveraging an agentic RCA tool, offering data lineage visualized as an interactive graph, with context provided via JSON.
