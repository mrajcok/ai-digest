Spreading the load: How Salesforce met Multi-AZ HA with SageMaker Inference Components

Amazon SageMaker AI Inference Components (ICs) now offer fine-grained control over placement across Availability Zones (AZs) with the new SchedulingConfig parameter in the CreateInferenceComponent API. This addresses a gap where ICs, while reducing GPU costs through co-hosting, lacked Multi-AZ high availability (HA) guarantees.

  • The SchedulingConfig parameter introduces AvailabilityZoneBalance to control cross-AZ distribution, allowing configurable imbalance tolerance.
  • PlacementStrategy within each AZ allows selection between SPREAD (distributing copies across instances for fault isolation) and BINPACK (packing copies onto fewer instances for utilization).
  • Salesforce achieved 8x infrastructure cost reduction using ICs, and then used SchedulingConfig with SPREAD and a MaxImbalance of 0 or 1 to meet 2-AZ compliance requirements.
  • Monitoring AZ balance is possible with SageMaker AI Insights, tracking metrics like AZ skew and IC copy count per AZ to detect and resolve imbalance after scaling events.
