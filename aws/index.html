Evaluate any agent framework with Amazon Bedrock AgentCore Evaluations

  • Amazon Bedrock AgentCore Evaluations decouples agent evaluation from the underlying agent framework by leveraging OpenTelemetry as a common standard for telemetry data.
  • The system focuses on classifying and extracting data from three span roles: invoke agent (user turn), inference (model calls), and execute tool (tool calls), while ignoring other spans for forward compatibility.
  • The service automatically detects how to read telemetry data based on the scope.name of the instrumentation library used (e.g., under opentelemetry.instrumentation.* or openinference.instrumentation.*), supporting frameworks like Strands, LangGraph, OpenAI Agents SDK, LlamaIndex, Google ADK, and Claude Agent SDK.
  • Evaluation requires a session.id attribute to group spans into sessions and access to message content either through correlated event records or directly on the spans; ADOT automatically injects the session ID on AgentCore runtime.

Agentic Resource Discovery (ARD): An open specification for agent discovery

AWS introduces Agentic Resource Discovery (ARD), an open specification for cross-environment agent discovery.

  • AWS Agent Registry provides a centralized, searchable catalog for agents, Model Context Protocol (MCP) servers, tools, and resources, utilizing registries and registry records.
  • The Agent Registry supports curation workflows with approval settings, hybrid search (semantic and keyword-based), and flexible authorization via IAM or JWTs.
  • ARD is an open standard (Apache 2.0 license, agenticresourcediscovery.org) designed to enable federation across registries, analogous to DNS, allowing discovery without requiring proprietary connectors.
  • AWS envisions ARD complementing AWS Agent Registry by enabling federated discovery across environments while maintaining local control and potentially opening paths for public discovery.

Reduce RAG costs on Amazon Bedrock with query-aware compression

Reduce RAG costs by filtering retrieved chunks with a smaller model before sending context to the primary model.

  • Amazon Bedrock enables a “query-aware compression” pattern where a smaller, lower-cost model (e.g., Anthropic Claude Haiku) filters retrieved chunks based on the user query.
  • This reduces the number of input tokens sent to the primary model (e.g., Anthropic Claude Sonnet), lowering costs, and potentially reducing hallucination by removing irrelevant context.
  • The implementation uses an AWS Lambda function with the Amazon Bedrock Converse API, adding a compression step before the final answer generation. The pattern achieved 33% cost savings in testing.
  • Key considerations include the price ratio between the models, inference speed, and maintaining answer quality – with tests showing minimal impact on correctness and a reduction in hallucination rate.

Asynchronous patterns for calling Amazon Bedrock AgentCore agents in serverless pipelines

Asynchronous invocation patterns for Amazon Bedrock AgentCore agents in serverless pipelines reduce costs by eliminating idle compute time while the agent processes requests.

  • The post details three patterns – task-token callback, direct service integration, and durable function – to avoid the cost of blocking compute services (like Lambda) while waiting for an AgentCore agent to respond.
  • Amazon Bedrock AgentCore runtime is consumption-based, billing only for memory during idle time (waiting on LLM generation or tool calls), unlike compute services that are billed for full compute allocation even while blocked.
  • Pattern 1 (task-token callback) uses Step Functions' waitForTaskToken integration with a dispatcher function, minimizing compute cost by pausing execution and resuming with a task token.
  • Pattern 2 (direct service integration) eliminates the dispatcher Lambda function entirely by leveraging Step Functions' direct integration with AgentCore, further reducing costs, while Pattern 3 (durable function) expresses orchestration as code in a single Lambda function that suspends during the wait.
