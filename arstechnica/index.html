What happens to mathematics when AI becomes an oracle?

What Happens to Mathematics When AI Becomes an Oracle?

A new book, Big Math: The Hidden Codes That Run Our World, by Steven Strogatz and Alex Townsend, explores the implications of AI and computing exceeding human mathematical capacity.

  • The book defines “big math” as problems exceeding human cognitive capacity, encompassing fields like civil engineering, medical imaging, and even lunar trajectory calculations—problems solvable with computers but intractable for manual calculation.
  • The authors highlight a shift in the role of computers from tools (“servants”) to exploratory agents (“scouts”) and now potentially to “oracles,” capable of producing results without explainable reasoning, as seen with tools like Google Translate and AlphaFold.
  • The discussion includes the application of mathematical principles to gerrymandering, illustrating how computational methods, while potentially revealing unfair map configurations, face resistance from legal systems prioritizing intuitive understanding over mathematical rigor.
  • The authors question whether reliance on computationally irreducible systems, as suggested by Stephen Wolfram, implies that accessible insight is limited to a small subset of naturally occurring phenomena and that most of nature may not yield to simplified, insightful theories.

Claude Code is accidentally exposing secrets all over GitHub

Claude Code is exposing sensitive information on public GitHub repositories due to settings file handling.

  • The issue stems from Claude Code saving user approvals for shell commands—including the commands themselves with embedded secrets—to a local settings file (.claude/settings.local.json).
