MCP for agent-to-agent comms may be the riskiest protocol you've never heard of

MCP, or Model Context Protocol, is a communication standard used by AI apps and agents that has demonstrated security vulnerabilities.

  • Researcher Syed Anas Mohiuddin identified vulnerabilities in MCP implementations across Google, JP Morgan Chase, Weviate, Rapid7, the French government, and the US federal government.
  • The attacks leverage trust gaps within MCP, potentially leading to server-side request forgery (SSRF) and allowing malicious instructions to propagate between agents.
  • Google addressed a vulnerability (CVE-2026-97228, severity 8.0) related to its googleapis/mcp-toolbox missing HTTP redirect and IP validation controls.
  • The researcher terms the attack method “protocol pivoting,” where initial access through one protocol (like MCP) escalates via trust assumptions to other protocols such as Google’s Agent-to-Agent (A2A) protocol.
