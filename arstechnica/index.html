Claude Code is accidentally exposing secrets all over GitHub

Claude Code is exposing sensitive information on public GitHub repositories due to settings file handling.

  • The issue stems from Claude Code saving user approvals for shell commands—including the commands themselves with embedded secrets—to a local settings file (.claude/settings.local.json).
  • While Anthropic includes a .gitignore entry to prevent sharing this file, it's not always reflected at the repository level, allowing accidental commits.
  • Apiiro researchers found over 100,000 instances of the settings file on public GitHub, with approximately 1,100 containing secrets like API tokens and database passwords.
  • Anthropic is investigating preventative measures, recommending use of Claude Code’s “auto mode” and exploring built-in secret scanning, although current secret scanners do not catch all exposed secrets.
