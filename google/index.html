AlphaGenome 2: Deciphering how cells read DNA to better understand disease

AlphaGenome 2 predicts how DNA sequences and variations impact specific human cell types, offering a significant improvement in variant predictive performance over prior work.

  • AlphaGenome 2 is a conditional model that predicts DNA effects for a single biological condition (tissue, cell type, or state) at a time, improving accuracy compared to the parallel approach of AlphaGenome 1.
  • Trained on over 107 million individual cell profiles across 68 tissues, the model identifies nearly twice as many variants that change gene expression in cells compared to the original AlphaGenome.
  • AlphaGenome 2 can generalize to new single-cell experiments without retraining, predicting effects in unseen cell states using only a small sample of cells.
  • The model predicts core DNA function readouts (gene expression, histone modifications, chromatin accessibility) and newly includes DNA methylation, with precomputed predictions available for trait-associated variants across hundreds of cell/tissue conditions.

Gemini Decisions API: Fast, calibrated multimodal decisions

  • The Gemini Decisions API, powered by the Gemini Decision 1 model (gemini-decision-1), enables fast, probabilistic decisions across multiple modalities (text, images, audio, video, PDFs) with up to 1,000 questions per input.
  • Gemini Decision 1 uses a single forward pass to score candidate options instead of token-by-token decoding, achieving 150-250ms end-to-end latency for inputs up to 256K tokens.
  • The API supports three decision types: noul (yes/no with confidence scores), choice (multiple choice with probabilities), and score (rubric-based grading with weighted scores).
  • Pricing is $0.10 per 1M input tokens with no charge for output tokens, significantly cheaper than the Interactions API for comparable tasks; an API no-cost tier is available via Google AI Studio.

EmbeddingGemma 2: an open, lightweight multimodal embedding model

EmbeddingGemma 2 is a new, open-source model for creating multimodal embeddings, unifying text, images, audio, and video into a single vector space.

  • Built on the Gemma 4 architecture with 740 million parameters, it achieves leading scores among sub-1B multimodal embedders on benchmarks like MTEB (Massive Text Embedding Benchmark) Code, MAEB (Massive Audio Embedding Benchmark) and others.
  • The model is modular, allowing developers to use as few as 270M parameters for text-only tasks, with optional encoders for vision (170M) and audio (300M) for full multimodal support.
  • EmbeddingGemma 2 uses Matryoshka Representation Learning (MRL) to reduce storage requirements, allowing dynamic truncation of output vectors to 768, 512, 256, or 128 dimensions, resulting in up to 6x storage reduction.
  • It features an 8K token context window and requires as little as ~191MB RAM (text-only) or ~567MB (full multimodal) on a Google Pixel 11 Pro with quantization, and demonstrates a 9.92-point improvement on code performance (MTEB Code, 68.76 to 78.68).

Introducing SynthID Bio

SynthID Bio introduces a watermarking system for AI-generated biological data to enhance biosecurity and scientific integrity.

  • SynthID Bio embeds imperceptible signatures into protein sequences and 3D structures, preserving biological function, using adjustments to amino acid choices and atomic coordinates.
  • The system was validated with AlphaProteo and a SynthID-enabled ProteinMPNN, demonstrating comparable hit rates and binding affinities (KD measurements) to unwatermarked proteins for VEGF-A, SARS-CoV-2 spike protein RBD, and PD-L1.
  • For protein folding, SynthID Bio fine-tunes AlphaFold 3’s diffusion network for watermark integration, maintaining prediction accuracy and detectability even with digital noise.
  • The approach is being extended to watermark entire genomes using Evo 2, and code, weights, and in vitro data are being open-sourced to encourage community collaboration.
