Putting sign language AI into users’ hands

Google DeepMind announced SL2T, a massively multilingual sign-language-to-text (SL2T) translation model, bringing sign language AI to consumer products for the first time.

  • SL2T translates sign language into text by processing pose landmark locations of the signer via the on-device MediaPipe Holistic model, achieving a 70 BLEURT score on the FLEURS-ASL benchmark (zero-shot).
  • The model was trained on over 100,000 hours of data across more than 50 sign languages, with approximately 25% of the data in American Sign Language (ASL), and bypasses intermediate “glosses” used in prior work by translating directly from landmarks.
  • SL2T is currently powering sign-to-text dictation in Gboard and Live Transcribe on Pixel 11 for American Sign Language (ASL) to English translation, with plans for expansion to more languages and devices.
  • Development involved close collaboration with the Deaf community, including the establishment of an AI Sign Language Advisory Committee (AISLAC) to guide responsible deployment and address user needs, like accounting for left-handed signers.

WeatherNext: AI model achieves breakthrough in forecasting cyclones

WeatherNext, an AI model from Google DeepMind and Google Research, achieves state-of-the-art accuracy in cyclone track, intensity, and wind structure forecasting, providing an average of 24 hours more lead time than previous models.

  • The model, WeatherNext Cyclones, leverages Functional Generative Networks (FGNs) to efficiently generate 1,000-member ensembles of predictions, capturing uncertainty and rare events.
  • It was co-trained on nearly 20 terabytes of global atmospheric data and the IBTrACS database containing nearly 5,000 historical storms to learn complex atmospheric patterns.
  • WeatherNext Cyclones performs well at a relatively coarse resolution of 28x28km, challenging the assumption that high-resolution data is essential for accurate intensity forecasts.
  • Google is open sourcing WeatherNext 2 and WeatherNext Cyclones, along with code and model weights, to empower the research community and improve global weather forecasting; a smaller version, WeatherNext 2-mini, is available in a public Colab notebook.

Gemini API Managed Agents: 3.6 Flash, hooks, and more

Gemini API Managed Agents now default to Gemini 3.6 Flash and introduce new capabilities for controlling and monitoring agent behavior.

  • Gemini 3.6 Flash is the default model, offering a balance of reasoning, coding, and tool use; alternatives include Gemini 3.5 Flash and Gemini 3.5 Flash-Lite for lower cost/latency, selectable via agent_config.model.
  • Environment hooks allow custom scripts to be executed before or after tool calls within the agent’s sandbox, enabling security checks, linting, and auditing through .agents/hooks.json configuration.
  • Budget controls can be implemented using max_total_tokens in agent_config to cap resource consumption and prevent runaway tasks, allowing paused execution to be resumed.
  • Scheduled triggers enable automated, recurring agent tasks based on a cron schedule, with persistent sandboxes retaining files between executions, and the Environments API allows listing/managing these sandboxes.
