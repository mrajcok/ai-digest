Session endpoints utilize authentication via SigV4 or JWT and support HTTP/1.1, HTTP/2, and WebSocket connections. Finally, Amazon Bedrock in AWS GovCloud (US) can now be configured with the ChatGPT desktop app, enabling access to OpenAI models within a secure, governed environment supporting Zero Data Retention and AWS SSO via IAM Identity Center.

Configure the ChatGPT desktop app with Amazon Bedrock in AWS GovCloud (US)

The ChatGPT desktop app now supports configuration with Amazon Bedrock in AWS GovCloud (US), enabling access to OpenAI’s models within a governed environment.

  • The solution utilizes the ChatGPT desktop app and Codex, routing model requests through Amazon Bedrock Mantle in the us-gov-west-1 region.

AWS blog · 2026-10-30

Preview web apps live as your coding agent builds them with Amazon Bedrock AgentCore runtime

Amazon Bedrock AgentCore runtime now allows for live web app previews as coding agents build them.

  • AgentCore runtime utilizes isolated microVMs for each agent session, enabling access via Session Endpoints – authenticated URLs that forward requests to specified ports (8000-12000).
  • Session Endpoints support HTTP/1.1, HTTP/2, WebSocket connections and require authentication via SigV4 (for IAM runtimes) or JWT (for authorizer runtimes).
  • The example deploys a coding agent with a Vite website, demonstrating real-time updates in the browser as the agent modifies code, accessed via http://localhost:8088.
  • The sample code utilizes ports 8090 (website) and 8081 (agent status), with requests to unauthorized ports or without credentials being refused by the runtime.
