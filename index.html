Anthropic research · 2026-11-04

Investigating vault particles with Claude

Anthropic researchers, using their Claude model, determined the first 3D structure of a vault particle found in prokaryotic cells—specifically, from a bacteriophage. Vaults are large protein shells whose function is currently unknown, but are present across most life forms. Claude assisted throughout the research by searching protein databases, optimizing particle isolation techniques, and processing microscopy data, accelerating the process from weeks to 34 hours for an initial structural model.

The prokaryotic vault is built from 96 copies of a single protein, L05, and is shorter and wider than its mammalian counterpart, enclosing 25% more volume. Experiments using Claude to design altered versions of the protein revealed key structural elements necessary for shell closure, and demonstrated the potential to modify vault size via protein duplication. This work suggests opportunities for adapting vaults for biotechnology, such as nanocapsules for enzyme delivery.

This research showcases a new approach to scientific discovery, with Claude substantially accelerating the research pipeline. The team has released their findings early to solicit collaboration and is actively investigating the vault’s function, with the ultimate goal of understanding its evolutionary origins and potential biological role.

Anthropic research · 2026-11-02

Progress on provable inference for large language models

Anthropic has developed FlashProve, a system for cryptographically proving that AI responses originate from a specific model – a technique known as provable inference. This addresses concerns about model substitution or tampering by allowing verification of each response without revealing the model’s weights. FlashProve leverages zkSNARKs to achieve this, demonstrating significantly faster proof generation than previous open-source systems.

Specifically, using a 400-billion parameter Llama 4 Maverick model (quantized to 4-bit precision), FlashProve generates proofs at approximately 110 tokens per second on a single H100 GPU, with each 1,024-token request requiring a 19 MB proof. This is 70-95 times faster than running inference with vLLM, a common open-source library. The system includes executable code, Lean formalizations (providing auditable security guarantees), and a technical report, all released under the Apache 2.0 license.

The work aims to accelerate development in provable inference and demonstrate the practicality of zero-knowledge succinct arguments for verifying AI outputs, addressing challenges in AI pacing, tamper detection, and text provenance. However, the current release is a research prototype with limitations including a focus on integer models with greedy decoding and no guarantees against side-channel attacks.

AWS blog · 2026-11-04

Four layers of context engineering for production AI agents: How Deep Insight applies them in working code

Four layers of context engineering for production AI agents: How Deep Insight applies them in working code

This post details a four-layer approach to context engineering for AI agents, addressing limitations of large language model (LLM) context windows, using the Deep Insight open-source solution as a reference implementation built on the Strands Agents SDK and Amazon Bedrock AgentCore.

  • Layer 1: Architecture - Isolate Context: Each agent operates with its own independent context, passing only compressed results to an orchestrator, minimizing shared information using a shared_state dictionary (messages, clues, full_plan, history).
  • Layer 2: Prompt Control - Limit Intake: Prompts are used to limit each agent’s output through explicit token budgets (e.g., Coder: 1,000-1,500 tokens) and standardized response formats (Status, Completed Tasks, Key Insights, Generated Files). A "self-contained code" principle ensures scripts include all necessary imports, avoiding reliance on prior context.
  • Layer 3: Tools - Externalize to Filesystem: Heavy content is moved out of the context window and into the filesystem using tools like a write_and_execute_tool which writes code to a file and only returns a summary; common logic is reused as modules to avoid code duplication.
  • Layer 4: Verification - Independent Agents/Safeguards: This layer provides a final line of defense with independent verification and safeguards to catch errors and prevent context overflow, though details of this layer are not as thoroughly illustrated in this post.
