Anthropic research · 2026-11-06

Teaching AI to build scientific models

Anthropic researchers are exploring how AI can aid in scientific modeling, a process historically demanding significant human effort. Their work centers around a three-step program – building, constraining, and interpreting models – mirroring the approach taken by Hodgkin and Huxley in their groundbreaking 1951 model of nerve cell firing. The core claim is that AI, specifically through simulation-based inference (SBI), can efficiently constrain models by generating numerous simulations and training neural networks to infer parameter ranges given observed data, a task previously computationally prohibitive for complex systems.

SBI bypasses the need for explicit formulas, enabling inference for simulators – models executable with parameters in and data out. Recent advances allow for rapid inference once simulations are complete, successfully applied in fields like cosmology and now nerve cell modeling, providing distributions of plausible parameters rather than single values. Furthermore, AI is beginning to assist in building models, generating candidate equations based on data and descriptions. However, the most challenging step remains interpreting the models – extracting meaningful understanding, not just data replication – for which the researchers suggest evaluating AI's ability to predict system responses to disturbances or aid human scientists.

Anthropic research · 2026-11-06

The components of agent memory

Anthropic researchers explored how to best design memory systems for AI agents, drawing parallels to human memory processes which involve both immediate encoding and later consolidation. They found that Claude, their model, can effectively organize its memory through a process akin to “dreaming”—reflecting on logs to correct errors, create notes, and build new representations. Claude can tag important events, write notes, and even predict future information needs.

Evaluations using the CL-Bench 1.0 benchmark showed that Claude Sonnet 5 and Opus 5.5 successfully created learning loops using memory, while Sonnet 4.6 generated theories but struggled to test them. In a Pokémon Red game test, Claude Fable 5, utilizing a more selective memory approach, earned four badges compared to Sonnet 3.7’s one due to indiscriminate logging. Dreaming was shown to correct errors—specifically, a misremembered location in Pokémon, leading to successful navigation—and construct useful knowledge structures like “wikis,” improving performance on tasks requiring information retrieval from a corpus of documents by up to 48%. These wikis grew in effectiveness with more “dreaming” sessions.

Agentic cheminformatics with Google Antigravity

Google Antigravity now includes new Cheminformatics Skills to accelerate drug discovery workflows.

  • The agent uses RDKit, ChEMBL, and PubChem to unify molecular data from various sources (IUPAC names, Markush structures, SDF files) and performs scientific reasoning.
  • Demonstrated on lung cancer treatments, the agent retrieved thousands of compounds, performed matched molecular pair analysis (MMPA), and proposed novel macrocycles with synthetic routes in approximately one hour.
