Anthropic blog · 2026-10-01

Customize Claude Code with mods in TypeScript | Claude by Anthropic

Anthropic has introduced “mods” for Claude Code, enabling users to customize the tool's behavior with small TypeScript functions. These mods function as event hooks – intercepting actions like tool calls or UI rendering – and can rewrite prompts, alter the interface, replace built-in features, or add new functionality. Mods are packaged and distributed as plugins, installing and updating like any other plugin within the Claude Code CLI and desktop app.

Importantly, mods run with the same system access as Claude Code itself, requiring trust in the source. Existing features like /diff are now implemented as mods, signaling a move to make more of Claude Code customizable in this way. Team and Enterprise plans include security features like sec-default which can restrict mod behavior, and allow administrators to define custom mod loading order and restrictions.

Users can author mods themselves, or instruct Claude Code to generate them. The full documentation and a getting started guide are available; admins can manage plugin access through existing controls.

Anthropic research · 2026-10-01

Claude-shaped science

Anthropic’s new toolkit, BootLoops, leverages the capabilities of Claude to tackle “Claude-shaped” problems – quantitative scientific questions particularly well-suited to AI’s strengths in coding, mathematical manipulation, and broad knowledge access. Researcher Matthew Schwartz found that by allowing Claude to identify these problems, rather than forcing it into pre-defined research paths, significant progress could be made across diverse fields. Initial experiments with Claude Opus 4.5 demonstrated performance comparable to a graduate student, but required extensive hand-holding; BootLoops aims to overcome that impedance mismatch.

BootLoops has already facilitated novel findings in areas like ecology (revealing discrepancies in tree species change rates compared to neutral theory) and population genetics (identifying a mechanism called gene conversion). The toolkit functions as a harness, streamlining code porting and enabling exact calculations, particularly with semi-numerical bootstrap methods. The project involved 36 manuscripts with 19 co-authors across 18 fields developed in three months, with the source code available on GitHub.

The key takeaway is that focusing on problems aligned with current AI capabilities—those requiring extensive computation and drawing on interdisciplinary knowledge—can unlock valuable scientific insights. While AI won't replace the need for human scientists to guide research and interpret results, it provides a powerful new tool for accelerating discovery, especially where existing expertise is fragmented across disciplines.

Google research · 2026-09-30

Introducing SynthID Bio

SynthID Bio introduces a watermarking system for AI-generated biological data to enhance biosecurity and scientific integrity.

  • SynthID Bio embeds imperceptible signatures into protein sequences and 3D structures, preserving biological function, using adjustments to amino acid choices and atomic coordinates.
  • The system was validated with AlphaProteo and a SynthID-enabled ProteinMPNN, demonstrating comparable hit rates and binding affinities (KD measurements) to unwatermarked proteins for VEGF-A, SARS-CoV-2 spike protein RBD, and PD-L1.
  • For protein folding, SynthID Bio fine-tunes AlphaFold 3’s diffusion network for watermark integration, maintaining prediction accuracy and detectability even with digital noise.
  • The approach is being extended to watermark entire genomes using Evo 2, and code, weights, and in vitro data are being open-sourced to encourage community collaboration.

AWS blog · 2026-10-02

Fine-tune a search agent with multi-turn RL on Amazon SageMaker AI

AWS has introduced multi-turn reinforcement learning (MTRL) within Amazon SageMaker AI to fine-tune Large Language Models (LLMs) for search agents.

  • MTRL optimizes LLMs across full conversational sequences, addressing limitations of supervised fine-tuning and single-turn RL by rewarding final outcomes.
  • The service offers a modular agent-environment interface, serverless execution with per-token pricing, asynchronous rollout, and a native algorithm library including PPO, CISPO, and IS losses.
  • The demonstration involved fine-tuning a Qwen3.6-27B model using datasets like FRAMES, BRIGHT, and WixQA, with a reward function based on nDCG@10 to improve search retrieval quality.
  • Results showed improvements in nDCG@10 on benchmarks like WixQA (+18.4%) and BrowseComp-Plus (+23.7%), along with a significant reduction in agent failures, particularly on BrowseComp-Plus (failure rate reduced from 22.89% to 0.68%).
AWS blog · 2026-10-02

Add secure Web Search to Claude Desktop with Amazon Bedrock AgentCore

Amazon Bedrock AgentCore now enables secure web search integration for Claude Desktop, overcoming knowledge cutoff limitations.

  • AgentCore Gateway, a component of Amazon Bedrock AgentCore, connects Claude Desktop to a web search capability backed by an Amazon web index spanning tens of billions of documents.
  • The integration uses JSON Web Token (JWT)-based authentication, federating AWS IAM Identity Center with Amazon Cognito to manage access without requiring external API keys or third-party identity providers.
  • Configuration involves creating an Amazon Cognito user pool, configuring IAM Identity Center as a SAML application, registering IAM Identity Center as a SAML IdP in Cognito, and creating a Cognito app client.
  • A Python script is provided to create the AgentCore Gateway with the Web Search tool attached, and further steps detail configuring Claude Desktop to utilize the new gateway and authentication details; currently available in us-east-1, eu-west-1, and ap-northeast-1 regions.
AWS blog · 2026-10-02

Sweep thousands of leases for compliance using Amazon Quick and the Adjudicated Query pattern

  • The Adjudicated Query pattern combines a natural language chat interface (Amazon Quick) with a deterministic rules engine to perform high-stakes compliance checks, such as verifying lease agreements against landlord-tenant laws.
  • The pattern prioritizes "provable completeness" and "defensibility" by ensuring all records are assessed and providing a clear audit trail of applied rules and data.
  • The architecture utilizes Amazon Quick, Amazon API Gateway, AWS Lambda (hosting the MCP server and rules engine), Amazon Aurora Serverless v2 (PostgreSQL with pgvector), and Amazon Bedrock (for exploratory clause search, not compliance sweeps). Specifically, it employs Amazon Titan Text Embeddings V2 and Anthropic Claude Sonnet 5.
  • The system enforces strict design rules – rules are data, not code; natural language doesn’t reach SQL; and filtering is exact for completeness, with vectors used only for ranking – to prevent silent errors and maintain data integrity.
