Anthropic research · 2026-11-02

Progress on provable inference for large language models

Anthropic has developed FlashProve, a system for cryptographically proving that AI responses originate from a specific model – a technique known as provable inference. This addresses concerns about model substitution or tampering by allowing verification of each response without revealing the model’s weights. FlashProve leverages zkSNARKs to achieve this, demonstrating significantly faster proof generation than previous open-source systems.

Specifically, using a 400-billion parameter Llama 4 Maverick model (quantized to 4-bit precision), FlashProve generates proofs at approximately 110 tokens per second on a single H100 GPU, with each 1,024-token request requiring a 19 MB proof. This is 70-95 times faster than running inference with vLLM, a common open-source library. The system includes executable code, Lean formalizations (providing auditable security guarantees), and a technical report, all released under the Apache 2.0 license.

The work aims to accelerate development in provable inference and demonstrate the practicality of zero-knowledge succinct arguments for verifying AI outputs, addressing challenges in AI pacing, tamper detection, and text provenance. However, the current release is a research prototype with limitations including a focus on integer models with greedy decoding and no guarantees against side-channel attacks.

How Circle K accelerated DevOps incident triage to under 15 minutes with Amazon Bedrock

Circle K reduced DevOps incident triage time to under 15 minutes using Amazon Bedrock, improving response times and consistency.

AWS blog · 2026-11-02

Build efficient agents with knowledge distillation on Amazon SageMaker AI

  • This blog details how to use sequence-level knowledge distillation (SeqKD) on Amazon SageMaker AI to fine-tune a shopping agent, transferring behavior from a larger "teacher" model (GLM-5.3 on Amazon Bedrock) to a smaller "student" model (Qwen3.5-4B).
  • SeqKD involves generating high-quality multi-step trajectories with the teacher model, filtering for successful task completion using a programmatic scorer (ShoppingBench), and then using these trajectories to train the student model with supervised fine-tuning.
  • The process focuses on encoding trajectories as a series of chat turns, compressing tool observations to manage token limits, and leveraging SageMaker AI model customization for serverless fine-tuning and model versioning.
  • Specific configurations for model customization are outlined, including hyperparameters like sequence length, LoRA rank, learning rate, and training epochs, with a focus on balancing performance and cost-effectiveness for agentic tasks.

Ars Technica news · 2026-11-02

Claude’s new rules against game cloning won’t stop the AI copying boom

Anthropic introduced a new system prompt to its Claude models to prevent the recreation of specific existing video games.

  • A new rule, named “tengu_heron_brook”, instructs Claude to build original games, games in a genre, or games from user designs, but not to recreate existing games, even if renamed.
  • The rule was added to version 2.1.314 of the Claude Code binary around October 27, and is also included in the Claude Opus 5.5 model's system prompt.
  • Anthropic states this change is to discourage IP infringement, as usage of Claude for this purpose violates their policy.
  • The company acknowledges that the new prompt may impact some legitimate game development use cases, but intends to iterate and balance restrictions.
