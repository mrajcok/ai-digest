How Warp builds self-improving agents on Claude | Claude by Anthropic

Warp has developed a self-improvement loop for agents built on the Claude Platform, utilizing a “skills”-based framework. Skills are file-based encodings of knowledge, keeping instructions separate from the prompt itself. This system employs two primary skills: a “base skill” containing domain knowledge for a specific task (like code review), and an “improver skill” that periodically analyzes human feedback on the base skill’s output.

The process involves capturing human feedback – ideally detailed explanations, not just simple approvals – and using the improver skill to propose small, focused edits to the base skill. These edits are submitted as pull requests, allowing for review and approval before being merged, thus continuously refining the agent’s performance. Warp has deployed this pattern across its open-source repo, for tasks like issue triage and spec writing.

Key recommendations from Warp include writing skills as guiding principles rather than rigid rules, explaining the rationale behind them, minimizing friction for providing feedback, and prioritizing quality feedback over quantity. They emphasize the reusability of the “improver skill” across different agent applications and the importance of maintaining human oversight in the loop.

Anthropic blog · 2026-08-26

Claude Cowork gets a built-in browser: nothing to install | Claude by Anthropic

Anthropic has added a built-in browser to Claude Cowork within the desktop application, eliminating the need for extensions. This allows Claude to independently navigate websites, read content, and complete forms directly within the interface—handling tasks like data extraction or form filling without accessing the user’s existing browser profile. The browser is isolated; it does not share tabs, bookmarks, or passwords, though users can selectively import logins from Chrome, Edge, or Firefox.

The built-in browser is initially rolling out to Pro, Max, and Team plan users, with Enterprise admins gaining control via Organization settings as of today. A key distinction is made between the new browser and the existing "Claude in Chrome" extension: the built-in browser tackles new web tasks while the extension works with already-authenticated sessions. Users can switch their preferred method in settings.

The new capability includes existing safety measures to mitigate prompt injection attacks, but Anthropic recommends beginning with trusted websites. The built-in browser is currently in beta on macOS, Windows and Linux desktop apps. Availability on the web or mobile devices requires an active desktop application.

Anthropic blog · 2026-08-26

Claude in Chrome is generally available | Claude by Anthropic

Anthropic has generally released Claude in Chrome for all paid plans, enabling the model to interact directly with webpages. This allows Claude to perform actions within the browser – reading, typing, clicking, form filling – without requiring manual approval for each step, though a safety classifier validates actions before execution.

A core focus of this release is improved resilience against prompt injection attacks, where malicious instructions are hidden within web content. Anthropic has expanded its training datasets and implemented probes to scan web content, as well as a safety classifier to verify actions against the user’s original request. Testing shows Claude Fable 5, Opus 5, and Sonnet 5 successfully resisted attacks in their Cowork harness, with a 0.3% success rate for Fable 5 when using stronger, professionally sourced attacks.

The feature is available as a Chrome Web Store extension and is manageable within Organization Settings for Enterprise plans. It currently does not support other Chromium browsers or mobile devices.

Microsoft blog · 2026-08-26

The Economics of Agent Optimization: Four ways to lower the cost

The Economics of Agent Optimization: Four Ways to Lower the Cost

This post details strategies within Microsoft Foundry for optimizing AI agent costs, moving beyond simply proving concepts to achieving measurable ROI.

  • Model Routing: Foundry Models’ Model Router dynamically dispatches requests to the most suitable model (including options for cost, quality, or a balance), supporting model subsets aligned with Azure Policy and built-in failover for resilience. Different deployment options (Standard, Priority Processing, PTUs, Batch) allow further optimization based on workload requirements.
  • Caching: Utilizing prompt caching (with discounted read costs on standard and provisioned deployments) and semantic caching via Azure API Management’s AI Gateway to reuse frequently used content (system instructions, tool schemas) and reduce token consumption. Optimizing prompt architecture to place stable content first maximizes cache effectiveness.
  • Prompt & Agent Optimization: Foundry provides automated tools – Prompt Optimizer (rewrites system instructions) and Agent Optimizer (runs agents against datasets, generates configurations, and scores results) – to improve efficiency and performance without infrastructure changes.
  • Observability & Evaluation: Foundry’s observability features (input/output tokens, cache hit rate, latency, model used, evaluation scores) alongside Azure budgets/alerts allow for tracking cost per request and cost per completed outcome to ensure optimizations maintain quality and deliver tangible savings.

Preparing data for supervised fine-tuning Part 1: Formatting and quality

Preparing data for supervised fine-tuning Part 2: Advanced data strategies

  • This post details advanced strategies for optimizing supervised fine-tuning (SFT) datasets, assuming data is already cleaned and formatted according to Amazon Nova's conversational schema.
  • Learning curve analysis is recommended to determine the optimal dataset size, training until gains from additional data diminish (less than 1-2% improvement in primary metric).

Mistral AI blog · 2026-08-20

Agentic Search. More accurate and efficient results from your AI systems.

Mistral AI has introduced Agentic Search, a new retrieval method designed to improve the accuracy and efficiency of AI systems when navigating complex data. Unlike traditional Retrieval-Augmented Generation (RAG) which relies on a single search pass, Agentic Search employs a multi-step loop of finding, inspecting, and verifying information using five tools: search, open, navigate, read, and grep. These tools function similarly to file system operations, allowing the model to refine searches and inspect source material directly, rather than being limited to pre-retrieved chunks.

Testing on FinanceBench (SEC filings) and OfficeQA Pro (Treasury Bulletins) demonstrates significant gains. With the Mistral Medium 3.5 model, adding the agentic loop improved accuracy on FinanceBench by +47.3 percentage points, and navigation tools added another +8.7pp. On OfficeQA Pro, accuracy increased by +27.1pp for MM 3.5 and a substantial +45.6pp for the larger GLM-5.2 model, to 51.9%. The iterative approach also reduced token usage by up to one-third and lowered p90 latency by up to 39.6% compared to one-shot RAG.

Agentic Search is available through the Mistral Search Toolkit, within Mistral’s Libraries in Studio and Vibe, and is designed to work with both cloud and on-premises deployments. The framework is model-agnostic and doesn't require fine-tuning, with performance expected to scale with future model improvements.
