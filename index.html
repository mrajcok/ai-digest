Projects redesigned: from folder to conversation | Claude by Anthropic

Anthropic has redesigned Projects within Claude Code, shifting from a folder-based organization to a conversational model, now available in beta. The system allows users to define a goal—like reducing app latency or migrating endpoints—and Claude autonomously breaks down the work, delegates it to parallel “threads” (which are individual Claude Code cloud sessions with their own branches and repos), and coordinates the resulting pull requests. Users can monitor and steer the process via a central project chat, or dive into individual threads for detail.

This new approach leverages a shared memory, allowing Claude to retain context across longer-running tasks and learn project specifics, reducing prompt engineering. Projects also include a library for managing files and generated artifacts. Users can adjust Claude’s behavior, such as check-in frequency and thread creation. Usage is tracked per-project, allowing control over model and effort levels and is subject to usage limits. Local execution is planned.

Currently, the updated Projects feature is in beta for select Claude Pro and Max subscribers using cloud sessions in Claude Code; broader access will follow. Existing projects remain functional and will be upgraded during the rollout.

The new AgentCore runtime: Elastic, optimized, and consistently fast starts

New AgentCore Runtime for Amazon Bedrock: Elastic, Optimized, and Fast

The new AgentCore runtime for Amazon Bedrock improves performance and cost efficiency for production agents by addressing memory management and cold start times.

  • The runtime now dynamically allocates and reclaims memory as needed during a session, billing only for memory actively used instead of peak allocation.
  • Cold start times are now consistent – approximately 2 seconds regardless of image size (from 200MB to 2GB) – achieved through snapshotting and restoring pre-initialized environments.

Mistral AI blog · 2026-09-09

Modernizing complex legacy code with AI agents.

Mistral AI successfully migrated 40,000 lines of Fortran 77 code for a European energy operator to C++, addressing the challenge of maintaining and extending aging scientific codebases. A key aspect of their approach was establishing a “parity harness” – a system to verify numerical equivalence between the original Fortran and the translated C++ code, using exported state snapshots and a test framework. This ensured accuracy before extensive agent-driven translation began.

Initial attempts at fully autonomous translation produced syntactically correct but structurally poor code, essentially “Fortran retyped in C++.” Subsequent iterations employed structured agent workflows, combining AI “agents” with human oversight – a “planner,” “coder,” “tester,” and reviewer – focusing on manageable code modules (~10,000 lines). They also leveraged agents to document the legacy codebase by analyzing its call graph and incorporating information from existing PDFs using Mistral's OCR technology.

The project highlights three key principles for successful legacy code modernization: prioritize building a validation harness before coding, ensure comprehensive documentation, and implement structured workflows combining AI autonomy with human review gates. Approximately 40,000 lines were converted in the first sprint of a 300,000-line codebase.
