How Cresta turned CX expertise into an agent builder on the Claude Agent SDK | Claude by Anthropic

Cresta has released Conductor, a natural language agent builder leveraging the Claude Agent SDK, designed to streamline the creation of AI agents for customer experience (CX) applications. Originally built internally using Claude Sonnet and Opus, Conductor guides users through agent development – from blueprinting to implementation and optimization – aiming to halve initial deployment time.

Conductor utilizes the Claude Agent SDK for tasks requiring adaptability, code execution, and iterative refinement, combined with Cresta’s proprietary conversation intelligence and CX expertise. It focuses on balancing deterministic workflows—crucial for regulated industries—with flexible, adaptive conversation handling. The platform emphasizes evaluation with specific metrics covering artifact usability, execution path, quality, and resource usage, and includes a system to rerun those evaluations after updates to Claude or Conductor itself.

Cresta emphasizes a “dogfooding” approach, internally validating Conductor before release, and focusing development on areas where they possess unique expertise, leveraging the Claude Agent SDK for core functionality. Conductor also allows teams to capture proven agent development patterns as reusable “skills”, fostering a knowledge flywheel for continuous improvement.

Initial programs are currently running in San Francisco, New York, and London.

Anthropic blog · 2026-10-01

Customize Claude Code with mods in TypeScript | Claude by Anthropic

Anthropic has introduced “mods” for Claude Code, enabling users to customize the tool's behavior with small TypeScript functions. These mods function as event hooks – intercepting actions like tool calls or UI rendering – and can rewrite prompts, alter the interface, replace built-in features, or add new functionality. Mods are packaged and distributed as plugins, installing and updating like any other plugin within the Claude Code CLI and desktop app.

Importantly, mods run with the same system access as Claude Code itself, requiring trust in the source. Existing features like /diff are now implemented as mods, signaling a move to make more of Claude Code customizable in this way. Team and Enterprise plans include security features like sec-default which can restrict mod behavior, and allow administrators to define custom mod loading order and restrictions.

Users can author mods themselves, or instruct Claude Code to generate them. The full documentation and a getting started guide are available; admins can manage plugin access through existing controls.

Google research · 2026-09-30

Introducing SynthID Bio

SynthID Bio introduces a watermarking system for AI-generated biological data to enhance biosecurity and scientific integrity.

  • SynthID Bio embeds imperceptible signatures into protein sequences and 3D structures, preserving biological function, using adjustments to amino acid choices and atomic coordinates.
  • The system was validated with AlphaProteo and a SynthID-enabled ProteinMPNN, demonstrating comparable hit rates and binding affinities (KD measurements) to unwatermarked proteins for VEGF-A, SARS-CoV-2 spike protein RBD, and PD-L1.
  • For protein folding, SynthID Bio fine-tunes AlphaFold 3’s diffusion network for watermark integration, maintaining prediction accuracy and detectability even with digital noise.
  • The approach is being extended to watermark entire genomes using Evo 2, and code, weights, and in vitro data are being open-sourced to encourage community collaboration.

AWS blog · 2026-10-05

Downgrading user roles in Amazon Quick

Amazon Quick offers methods for downgrading user roles to enforce least privilege and potentially reduce costs.

  • Quick supports user management via Quick Identity, AWS IAM Identity Center, or Active Directory, with roles including Admin, Author, and Reader.
  • Direct downgrades from Admin/Author to Reader are not supported in the console or via the API; a step-down sequence is required (Admin > Author > Restricted Reader > Reader or Author Pro > Author > Restricted Reader > Reader Pro).
  • Downgrades can be achieved through a manual deletion-and-recreation process or via the AWS CLI using the update-user command with a specific role sequence.
  • A provided script automates the CLI-based step-down process for multiple users, reading usernames and emails from a file and handling error conditions during the transition.
AWS blog · 2026-10-05

Agentic retrieval with LangChain and Amazon Bedrock Knowledge Bases

Agentic retrieval with Amazon Bedrock Managed Knowledge Bases improves RAG applications by addressing limitations of standard retrieval when handling multi-faceted questions.

  • Amazon Bedrock Managed Knowledge Bases removes the need for self-managed vector stores, embeddings, and re-ranking models, handling chunking, embedding, storage, and retrieval automatically.
  • Agentic retrieval, available through the AgenticRetrieveStream API, plans retrieval by breaking down complex questions into sub-queries, iteratively searching, and evaluating evidence sufficiency.
  • The langchain-aws package provides access to both standard (AmazonKnowledgeBasesRetriever) and agentic retrieval (agentic_retrieve) methods for LangChain applications, requiring langchain-aws>=1.6.3 and boto3>=1.43.32.
  • To observe the agentic retrieval process, the agentic_retrieve_stream function in bedrock-agent-runtime can be used to stream trace events, revealing the planning steps and sub-queries generated by the model.

Cloudera and Mistral Partner to Bring Specialized, Sovereign Intelligence to Enterprise Data

Mistral AI and Cloudera have partnered to offer enterprises greater control over their AI deployments. The core offering focuses on enabling inference and custom model training directly within a customer’s existing data environment—whether on-premise, in a private cloud, public cloud, or even air-gapped systems. This addresses the need for “sovereign AI,” where data, compute, and operations remain fully under customer control.

The partnership emphasizes a shift from relying on generic, rented AI models to owning specialized intelligence built on an organization’s unique data assets. Cloudera manages 30 exabytes of customer data, providing a substantial base for these customized AI applications.
