Which Claude model should you build with? Fable, Opus, Sonnet, or Haiku / claude.dev Blog

Anthropic has released four generally available Claude models: Haiku 5.5, Sonnet 5.5, Opus 5.5, and Fable 5.2, with Claude Mythos 5.2 available via verification programs. The recommendation is to begin most tasks with Opus 5.5 at medium effort, due to its balance of cost (half that of Fable 5.2) and capability.

For specific applications, Haiku 5.5 is best for simple, high-volume tasks like classification; Sonnet 5.5 suits well-scoped work such as bug fixes or everyday document creation; and Fable 5.2 excels in complex technical projects, and when Opus 5.5 at high effort is insufficient. Adjusting the “effort” level is encouraged as a granular way to tune cost and capability, and combining models—using smaller models as subagents for larger ones—can optimize workflows.

Considerations for model migration include compatibility checks, specifically regarding preserved thinking, tool use (especially the computer toolset), and safety fallbacks. The blog stresses the importance of measuring model performance on your own tasks with representative data and clear outcome checks to determine the most cost-effective and accurate solution.

Anthropic blog · 2026-11-09

Safely scaling multi-agent teams with Claude Fable 5.2 / claude.dev Blog

Anthropic researchers demonstrated the scalability of multi-agent systems using an early version of Claude Fable 5.2 by reproducing a formal proof of Fermat’s Last Theorem. A team of 1,000 agents, operating within sandboxed environments and monitored by both real-time and offline classifiers, completed the task in 28.7 hours, using one-third the output tokens and one-seventh the code length of a previous, researcher-guided attempt using Claude Fable 5.1 and the Prove2Me platform.

The agents were provided with 60 statements related to the theorem, including a sketch of the solution and 47 previously proved lemmas, and given access to tools like a shell, file editor, Lean’s toolchain, and a shared PostgreSQL database for coordination. The agents self-organized, establishing a lead-helper hierarchy and utilizing the database to claim tasks, share notes, and track progress. The system included safety measures like blocking shell commands and file edits and a kernel designed to prevent sandbox escapes. This experiment indicates that agent teams can tackle complex, long-horizon goals with appropriate safety controls.

Anthropic research · 2026-11-09

Claude can design electronic prototypes from start to finish

Anthropic’s Claude Fable 5.2 can now design and prototype electronic hardware from start to finish with minimal prompting. Working with Diode Computers, Claude designed a speakerphone, a voice-assistant hub, and a handheld virtual pet—all of which function after weeks of use. The significant improvement over previous models, including Fable 5 (25% on the Diode PCB Gym benchmark) and Fable 5.1, stems from Fable 5.2’s ability to reason through complex geometric problems, such as component placement and signal routing, achieving a score of 69% on the Diode PCB Gym benchmark and 83.5% on BenchCAD 2.1.

Crucially, Claude 5.2 revises its own work, addressing issues like signal routing and component crowding without needing intervention. It leverages datasheets to inform design decisions and even wrote its own routing algorithm to handle complex board layouts, and performed design-for-manufacturing checks. While these are early prototypes requiring further testing and certification, this demonstrates a substantial leap in AI-driven hardware engineering, reducing the need for iterative manual adjustments typically required in the manufacturing process.

Agentic cheminformatics with Google Antigravity

Google Antigravity now includes new Cheminformatics Skills to accelerate drug discovery workflows.

  • The agent uses RDKit, ChEMBL, and PubChem to unify molecular data from various sources (IUPAC names, Markush structures, SDF files) and performs scientific reasoning.
  • Demonstrated on lung cancer treatments, the agent retrieved thousands of compounds, performed matched molecular pair analysis (MMPA), and proposed novel macrocycles with synthetic routes in approximately one hour.

AWS blog · 2026-11-10

How skills and agents work in AWS Quick

AWS Quick introduces skills and agents for automating tasks and analyzing data using natural language.

  • AWS Quick uses agents that follow instructions, load relevant skills, and access data through connectors (like Outlook, Slack, Jira) and data sources (spaces, knowledge bases, datasets, dashboards).
  • Custom agents can be configured for specific jobs with tailored instructions and limited access to resources, while the default "Quick" agent has broad access.

  • Skills can be built from chat interactions or files, published, and shared within an AWS Quick account, and best practices (testing, failure handling, versioning) are recommended for production use with resources available in the official AWS Quick catalog.

Le Chonk: Built for Coders, Trusted by Defenders.

Mistral AI has released Mistral Large 4, dubbed “Le Chonk,” a 1-trillion-parameter multimodal model now available with open weights.
