Gemini 4 Carbon: Our next frontier model

Gemini 4 Carbon, Google’s strongest model, achieves state-of-the-art performance in cybersecurity and long-horizon capabilities.

AWS blog · 2026-10-29

How MoEngage turned over 400 APIs into agent tools with AgentCore Gateway

MoEngage leveraged Amazon Bedrock AgentCore Gateway to expose 400 internal APIs to AI agents without public exposure or extensive platform engineering.

  • AgentCore Gateway, a managed MCP server, automatically generates MCP tools from OpenAPI specifications, eliminating the need for individual teams to implement MCP servers.
  • Cedar policies are used for server-side authorization, controlling tool access based on the agent's IAM role, ensuring only permitted tools are visible in the agent’s tools list.
  • Amazon VPC Lattice provides managed egress for private connectivity to internal services, avoiding the need for per-API networking configurations and simplifying regional deployments.
  • Semantic search ( x_amz_bedrock_agentcore_search capability) allows agents to discover tools by describing the desired task, reducing reliance on exact tool names and improving usability while minimizing context window usage.
AWS blog · 2026-10-29

Lend and borrow resources across teams with AWS Batch’s quota management for SageMaker Training jobs

AWS Batch now supports quota management for SageMaker Training jobs, enabling resource lending and borrowing between teams.

  • Administrators can define quota shares – virtual queues – organized by team or project, with configurable resource-sharing strategies: RESERVE, LEND, or LEND_AND_BORROW.
  • LEND_AND_BORROW allows idle capacity to be automatically shared and reclaimed when needed, utilizing compute more efficiently.
  • In-share preemption can be enabled to prioritize jobs within a quota share, preempting lower-priority jobs.
  • The SageMaker Python SDK v3 has been extended to allow submission of training jobs to these quota-managed AWS Batch job queues (using TrainingQueue).

Mistral AI blog · 2026-10-20

Voxtral 3

Mistral AI has released Voxtral 3, a new family of speech models and a voice agent SDK designed for building real-time, multi-step conversational AI. It includes Voxtral Small Transcribe 3 and Voxtral Mini Transcribe 3 for speech-to-text, achieving state-of-the-art results in multilingual transcription (50+ languages) and diarization, outperforming models like Whisper and Gemini. Context biasing improves accuracy with domain-specific vocabulary.

The system also features Voxtral Mini TTS 3 for text-to-speech, offering natural-sounding speech with emotion and expression in 35+ languages and 50+ dialects. A key component is the voice agent SDK, integrating these models into a streaming pipeline for low-latency interaction—under one second per turn— and enabling tool calling, web search, and integration with existing systems via SIP and WebRTC.

Voxtral 3 prioritizes data sovereignty, with options for deployment via Mistral’s EU-hosted API or self-hosting. Pricing ranges from $0.0035/min for Mini Transcribe (batch) to $13/1M characters for Voxtral Speech 3.
