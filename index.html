Self-service data analytics in Slack: how Anthropic deploys Claude Tag for ad-hoc questions | Claude by Anthropic

Anthropic has deployed Claude Tag, currently in public beta, to enable self-service data analytics directly within Slack. Building on a foundation of governed semantic layers and analytical skill files (as described in a previous post), Claude Tag allows anyone to ask data-related questions and receive answers aligned with established analytical standards. A key architectural decision was to treat skill files as continuously refreshed content, ensuring Claude doesn’t rely on outdated information—the system remounts and re-reads skills on every conversation.

Beyond simply retrieving data, Claude Tag is equipped with specialized “runbook” skills including forecasting, cohort analysis, funnel analysis, charting conventions, and analytical writing—capabilities that go beyond basic querying to provide insightful answers, similar to a data analyst’s approach. To provide complete context, the system is also integrated with an internal knowledge index, surfacing relevant information from Slack threads, incident trackers, and documentation alongside quantitative data.

Security is addressed by limiting the service account’s data access to governed data and denying access to PII at the column level, alongside detailed logging of queries and user interactions. The team emphasizes careful permissioning, continuous monitoring of skill freshness and accuracy (through user feedback and telemetry), and incremental skill development informed by actual user questions. This aims to accelerate self-service analytics adoption by embedding data insights directly within existing workflows.

Google research · 2026-08-12

Putting sign language AI into users’ hands

Google DeepMind announced SL2T, a massively multilingual sign-language-to-text (SL2T) translation model, bringing sign language AI to consumer products for the first time.

  • SL2T translates sign language into text by processing pose landmark locations of the signer via the on-device MediaPipe Holistic model, achieving a 70 BLEURT score on the FLEURS-ASL benchmark (zero-shot).
  • The model was trained on over 100,000 hours of data across more than 50 sign languages, with approximately 25% of the data in American Sign Language (ASL), and bypasses intermediate “glosses” used in prior work by translating directly from landmarks.
  • SL2T is currently powering sign-to-text dictation in Gboard and Live Transcribe on Pixel 11 for American Sign Language (ASL) to English translation, with plans for expansion to more languages and devices.
  • Development involved close collaboration with the Deaf community, including the establishment of an AI Sign Language Advisory Committee (AISLAC) to guide responsible deployment and address user needs, like accounting for left-handed signers.

Mistral AI blog · 2026-08-04

Introducing Shieldstral.

Mistral AI has released Shieldstral, a 3 billion parameter open-weights model designed for multimodal safety classification. The core innovation is framing content moderation as a question-answering task, allowing users to define safety policies in plain language at inference time without requiring model retraining. Shieldstral accepts a structured input consisting of an instruction, a yes/no query representing the safety policy, and the content to be evaluated (text, image, or both), then outputs a calibrated safety score.

The model is designed to rival the performance of models up to seven times its size on text safety and achieves state-of-the-art results on multimodal moderation tasks. It was trained on a combination of real and synthetically generated data and requires only a single 16GB NVIDIA GPU for operation. Shieldstral is available under the Apache 2.0 license and was created utilizing Mistral’s Forge platform.

Key to Shieldstral's performance is its approach to data handling: unifying diverse datasets, teaching the model to discriminate between similar policies rather than memorizing labels, incorporating image data, and combining multiple fine-tuned checkpoints.

Mistral AI blog · 2026-07-09

Your Prompts and Skills need a system of record.

Mistral AI’s Studio now offers a system of record for managing AI prompts and skills, addressing the common enterprise problem of scattered and unmanaged instructions. This feature treats prompts as production assets, providing version control, ownership, and audit logs to ensure AI behavior is governed and traceable. Every prompt or skill receives an immutable version, a designated owner, and can be labeled for classification (e.g., “Production” vs. “Staging”).

The system aims to accelerate iteration by allowing quick testing of changes without requiring full CI/CD pipelines, while still maintaining enterprise-level controls for deployment. Domain experts can directly improve production instructions, triggering existing CI/CD processes via the Mistral SDK. Importantly, Studio connects these governed assets to runtime behavior through observability, lineage, and telemetry, tracing outputs back to specific versions and usage data.

This differs from standalone prompt catalogs by providing a closed-loop system where behavior is defined, monitored, and improved against a single source of truth, helping organizations maintain compliance and reduce risk related to ungoverned AI instructions. The feature is currently available to Mistral Studio customers.

Ars Technica news · 2026-08-13

Claude's new Scarlet Letter watermark is invisible—for now

Anthropic will soon watermark content processed or generated by its Claude models to comply with the EU AI Act.

  • All new Claude models will be watermarked globally “from day one.”
  • Text outputs will include embedded, invisible watermarks that bias word choices, while other file types will use digitally signed metadata (C2PA).
  • Anthropic is applying watermarks broadly – even to processed content like grammar corrections – despite exemptions in the EU AI Act.
  • The company plans to release a detection tool but acknowledges watermarks are easily bypassed and may not definitively indicate AI generation; a lack of a watermark does not guarantee content is not AI-generated.
