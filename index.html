Anthropic research · 2026-10-08

Using Claude Science to produce the first complete map of the sky in UV light

Anthropic researchers, led by astrophysicist Brice Ménard, used Claude Science to generate the first complete ultraviolet (UV) map of the sky. This was achieved by combining existing data from telescopes like NASA’s GALEX, Swift, and Korea’s FIMS/SPEAR with AI-driven inpainting to fill in approximately one-third of the sky never before observed in UV.

The process involved Claude orchestrating a team of AI agents to download, calibrate, and merge data from various sources. Specifically, Claude employed inpainting—a machine learning technique—to predict UV brightness in unobserved regions, guided by relationships learned from areas with existing UV and other wavelength data (visible, infrared, radio). The model's predictions were validated to be within about 10% of real UV measurements.

The resulting map reveals structures like dust clouds around young stars and faint filaments of dust, and incorporates UV light estimates for over 100 million stars using data from the European Space Agency’s Gaia satellite. The collaboration demonstrated a significant reduction in the time required for complex astronomical data processing, enabling completion of a long-standing project previously hampered by the tediousness of manual calibration and analysis.

Anthropic research · 2026-10-08

An opt-in vulnerability-finding service for open-source software

Anthropic is launching OSS Scanner, an opt-in vulnerability scanner for open-source software, inspired by Google’s OSS-Fuzz. This service uses Anthropic’s strongest language models – including Claude Mythos – to scan code and deliver vulnerability reports directly to maintainers, potentially much faster than traditional methods. The reports include a self-contained reproducer, an explanation of the vulnerability (with a bisection when possible), and a candidate patch.

Recent LLM advances have dramatically improved vulnerability discovery; LLMs now find over 85% of vulnerabilities on the CyberGym benchmark, versus under 20% last year. Anthropic has already discovered over 29,000 candidate vulnerabilities, including findings that led to unauthenticated remote code execution exploits in projects like PostgreSQL, OpenSSL, curl, wolfSSL, and HotCRP. A validation study of 97 critical/high-severity reports showed 88% met Anthropic’s CVD process standards.

Because OSS Scanner delivers model-generated outputs without human review, reports may contain inaccuracies; however, maintainers can opt-in for fast-track access to unverified reports. Eligible open-source projects – those with “critical impact on infrastructure and user security” – can enroll via a pull request to a specified GitHub repository.

Google research · 2026-10-06

EmbeddingGemma 2: an open, lightweight multimodal embedding model

EmbeddingGemma 2 is a new, open-source model for creating multimodal embeddings, unifying text, images, audio, and video into a single vector space.

  • Built on the Gemma 4 architecture with 740 million parameters, it achieves leading scores among sub-1B multimodal embedders on benchmarks like MTEB (Massive Text Embedding Benchmark) Code, MAEB (Massive Audio Embedding Benchmark) and others.
  • The model is modular, allowing developers to use as few as 270M parameters for text-only tasks, with optional encoders for vision (170M) and audio (300M) for full multimodal support.
  • EmbeddingGemma 2 uses Matryoshka Representation Learning (MRL) to reduce storage requirements, allowing dynamic truncation of output vectors to 768, 512, 256, or 128 dimensions, resulting in up to 6x storage reduction.
  • It features an 8K token context window and requires as little as ~191MB RAM (text-only) or ~567MB (full multimodal) on a Google Pixel 11 Pro with quantization, and demonstrates a 9.92-point improvement on code performance (MTEB Code, 68.76 to 78.68).

Introducing Mistral Large 4

Mistral AI has released a public preview of Mistral Large 4 (ML4), their largest and most capable model to date. This 1 trillion-parameter, natively multimodal model utilizes 49 billion active parameters and demonstrates competitive performance against leading open-source models, and surpasses other open-weight models, particularly in European and US development. ML4 was trained on 3,800 NVIDIA Grace Blackwell GPUs within Mistral’s European datacenters.

The model excels in areas like coding (achieving 61.7% on DeepSWE v1.1), agentic workflows (59.9% on AutomationBench), and, notably, cybersecurity, where it achieves 82% accuracy on reproducing and patching software vulnerabilities – outperforming closed models often restricted by safety filters. It shows strong multimodal understanding, surpassing even closed models in visual grounding tasks like analyzing satellite imagery and engineering drawings.

ML4’s development included extensive reinforcement learning, processing roughly 33 billion tokens daily. The weights will be released at the end of the month, following red-teaming with cybersecurity experts and authorities. It’s designed for both cloud and on-premise deployment with a particular focus on data sovereignty, with a European deployment operating entirely within European legal frameworks.
