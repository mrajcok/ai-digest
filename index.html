Today’s AI developments center on bringing large language models directly into user workflows, with a strong emphasis on privacy and open-source alternatives. The focus on open-weight models and privacy represents a counterpoint to the prevailing narratives surrounding data collection and proprietary AI systems. It is notable as a concerted attempt to offer a competitive alternative that prioritizes user agency and data protection within the emerging landscape of AI-powered browsing experiences.

Build a serverless PII redaction pipeline with Amazon Bedrock Data Automation

Organizations can automate PII redaction from documents and images at scale using Amazon Bedrock Data Automation (BDA).

  • BDA’s custom blueprint feature allows defining named document fields and using plain-language instructions for precise extraction of data to redact, instead of relying on traditional OCR and pattern matching.
  • Blueprints are designed by scoping sensitive information, identifying its location on the page, and defining how to remove it – in this case, converting PDFs to PNGs and applying black box redaction based on bounding box coordinates obtained from BDA.
  • Combining BDA’s custom output (blueprint-driven PII detection) with its standard output (complete extraction with bounding boxes) and token matching improves redaction recall from 89.3% to 95.2%, with a minor trade-off in precision.
  • A serverless pipeline using AWS Step Functions and Lambda functions orchestrates the process, handling document input from S3, preprocessing (PDF to PNG conversion), redaction via BDA, reassembly into redacted PDFs, and reporting.

Mistral AI blog · 2026-09-09

Modernizing complex legacy code with AI agents.

Mistral AI successfully migrated 40,000 lines of Fortran 77 code for a European energy operator to C++, addressing the challenge of maintaining and extending aging scientific codebases. A key aspect of their approach was establishing a “parity harness” – a system to verify numerical equivalence between the original Fortran and the translated C++ code, using exported state snapshots and a test framework. This ensured accuracy before extensive agent-driven translation began.

Initial attempts at fully autonomous translation produced syntactically correct but structurally poor code, essentially “Fortran retyped in C++.” Subsequent iterations employed structured agent workflows, combining AI “agents” with human oversight – a “planner,” “coder,” “tester,” and reviewer – focusing on manageable code modules (~10,000 lines). They also leveraged agents to document the legacy codebase by analyzing its call graph and incorporating information from existing PDFs using Mistral's OCR technology.

The project highlights three key principles for successful legacy code modernization: prioritize building a validation harness before coding, ensure comprehensive documentation, and implement structured workflows combining AI autonomy with human review gates. Approximately 40,000 lines were converted in the first sprint of a 300,000-line codebase.
