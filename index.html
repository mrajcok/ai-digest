Anthropic research · 2026-10-20

How Claude designed protein binders against scorpion neurotoxins

Anthropic’s internal research model, operating within Claude Science, successfully designed protein binders against five scorpion neurotoxins (Cn2, Ts1, AaH I, AaH II, and LqhIII) with minimal human intervention. Prompted with a modified version of a prior protein-binder study, Claude generated 318,484 designs, selecting 180 for experimental testing. Partners at Adaptyv Bio and Twist Bioscience validated 17 of these designs as binders—proteins that tightly attach to their target toxins—using surface plasmon resonance to measure dissociation constants (KD).

The campaign, consuming roughly 10,000 GPU hours, demonstrated Claude’s ability to design binders targeting both individual toxins and groups of toxins, though multi-toxin binders were less successful. Notably, the best binders, Cn2-B1 and Cn2-B2, targeting the Centruroides noxius toxin, showed single-digit nanomolar affinities (KD) and appear to bind to the same site as a known neutralizing antibody (LR). While these results are promising, the designed binders haven’t been tested for neutralizing venom in vitro or in vivo, and further research is needed to develop a functional antivenom. All 211 designs and associated data have been publicly released.

Anthropic research · 2026-10-20

Using Claude to reduce the attack surface of code

Anthropic researchers investigated using their Claude model to automatically reduce the “attack surface” of code – the amount of code accessible to potential attackers – as an alternative to solely focusing on identifying and patching individual vulnerabilities. They applied Claude to 25 open-source projects (over 5 million lines of code in C, C++, Java, PHP, and Python), identifying 493 issues across three methods: default configuration issues, problematic configuration interactions, and code reachable before essential security controls.

Specifically, Claude found unnecessary pre-authentication code in 11 "gated" projects, 162 security-weakening configuration combinations, and cases where disabling security checks occurred silently. A notable case study involved OpenSSH, where Claude identified 4,500 lines of potentially reachable, experimental code for a new signature algorithm that should have been behind a configuration check; this was addressed in OpenSSH version 10.6.

Anthropic is developing a reusable Claude skill leveraging these techniques for integration into OSS-Scanner to automate this attack surface reduction process, focusing on default configuration, pre-authentication reachability, and harmful configuration combinations, alongside verification via existing test suites.

Build a semantic layer for agentic AI on AWS with AtScale and Amazon Bedrock AgentCore

AWS announces a method for building semantic layers for agentic AI using AtScale and Amazon Bedrock AgentCore, focusing on a Customer 360 (C360) use case with data from Amazon Redshift.

  • AtScale utilizes the Semantic Modeling Language (SML), a YAML-based specification versioned in Git, to define a dimensional model (dimensions, hierarchies, measures) exposed via SQL, XMLA, and the Model Context Protocol (MCP).
  • Amazon Bedrock (Anthropic Claude Sonnet 4.6) is used for planning and query generation, while Amazon Bedrock AgentCore hosts the Strands agent and manages credentials for AtScale access.
  • The solution allows for joins, metric definitions, and filters to reside within the semantic layer, improving performance through AtScale’s autonomous aggregate management and pushing queries down to native SQL in Amazon Redshift.
  • The architecture incorporates Amazon Bedrock AgentCore Identity for propagating user identity and enforcing role-based access control (RBAC) within AtScale, deployed on Amazon EKS via a Helm chart (AtScale C2026.7 release).

Mistral AI blog · 2026-10-20

Voxtral 3

Mistral AI has released Voxtral 3, a new family of speech models and a voice agent SDK designed for building real-time, multi-step conversational AI. It includes Voxtral Small Transcribe 3 and Voxtral Mini Transcribe 3 for speech-to-text, achieving state-of-the-art results in multilingual transcription (50+ languages) and diarization, outperforming models like Whisper and Gemini. Context biasing improves accuracy with domain-specific vocabulary.

The system also features Voxtral Mini TTS 3 for text-to-speech, offering natural-sounding speech with emotion and expression in 35+ languages and 50+ dialects. A key component is the voice agent SDK, integrating these models into a streaming pipeline for low-latency interaction—under one second per turn— and enabling tool calling, web search, and integration with existing systems via SIP and WebRTC.

Voxtral 3 prioritizes data sovereignty, with options for deployment via Mistral’s EU-hosted API or self-hosting. Pricing ranges from $0.0035/min for Mini Transcribe (batch) to $13/1M characters for Voxtral Speech 3.

Mistral AI blog · 2026-10-15

Introducing Timestral

Mistral AI has released Timestral, a family of time-series foundation models designed for probabilistic, multivariate forecasting. The models come in four sizes – 5M, 28M, 123M, and 209M parameters – and achieve state-of-the-art results on the GIFT-Eval, TIME, and fev-bench benchmarks, even surpassing larger models with only two-thirds the parameters. Importantly, Timestral can run efficiently on CPUs, with the 209M parameter model forecasting one day ahead in 140ms on a standard 8-thread server.

The models incorporate several key technical innovations, including decoupled horizon forecasting (DHF) – which preserves the full historical context during training – and covariate-aware attention, allowing the model to effectively utilize past, present and future information. Timestral was initially pre-trained on synthetic data and then post-trained on a mix of real and synthetic data, utilizing a pinball loss function over 21 quantiles.

For organizations requiring customization, Timestral is accessible via Mistral Forge, enabling fine-tuning on proprietary data, control over training data mix, and deployment in various environments, including air-gapped setups. The models accept multivariate time series, past and known future covariates, outputs probabilistic forecasts with 21 quantiles, and support context lengths up to 32,768 time steps.

Mistral AI blog · 2026-10-06

Introducing Mistral Large 4

Mistral AI has released a public preview of Mistral Large 4 (ML4), their largest and most capable model to date. This 1 trillion-parameter, natively multimodal model utilizes 49 billion active parameters and demonstrates competitive performance against leading open-source models, and surpasses other open-weight models, particularly in European and US development. ML4 was trained on 3,800 NVIDIA Grace Blackwell GPUs within Mistral’s European datacenters.

The model excels in areas like coding (achieving 61.7% on DeepSWE v1.1), agentic workflows (59.9% on AutomationBench), and, notably, cybersecurity, where it achieves 82% accuracy on reproducing and patching software vulnerabilities – outperforming closed models often restricted by safety filters. It shows strong multimodal understanding, surpassing even closed models in visual grounding tasks like analyzing satellite imagery and engineering drawings.

ML4’s development included extensive reinforcement learning, processing roughly 33 billion tokens daily. The weights will be released at the end of the month, following red-teaming with cybersecurity experts and authorities. It’s designed for both cloud and on-premise deployment with a particular focus on data sovereignty, with a European deployment operating entirely within European legal frameworks.

Ars Technica news · 2026-10-20

Meta Muse exposes users' personal and business secrets when they share conversations

Meta’s new AI agent, Muse, has a sharing feature that inadvertently exposes user data.

  • Researchers at Claroc discovered approximately 6,800 publicly discoverable share links created by Muse users.
  • Exposed data included sensitive information such as executive search details, internal revenue reviews, loan applications, financial records, and vacation schedules.
  • The vulnerability stems from Muse's URL structure, which includes conversation titles in the subdomain, making them easily searchable via passive DNS records.
  • Meta has temporarily suspended the sharing functionality while they review the issue; the findings were reported via their bug bounty program on October 8.
