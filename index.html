Anthropic research · 2026-10-22

LLMs are making formal software verification feasible at a much larger scale

Anthropic researchers demonstrated that Large Language Models (LLMs), specifically Claude, can now produce formal proofs at a large scale, enabling new software development workflows with proven security guarantees. Using Claude, they proved security properties at the assembly code level (RISC-V) for over 100 open-source libraries, a first for production software. This involved automatically converting existing compilable test suites into formal specifications – essentially proving the tests will always pass – and Claude successfully patched discovered bugs before completing these proofs.

The process revealed bugs previously undetected despite extensive testing, including issues requiring specific input sizes or call sequences. Crucially, Claude generated approximately 180 million lines of Rocq proof code, validated by a proof checker, reducing the need for manual review to trusting core components like the RISC-V and Linux models, the theorems, and the checker itself.

Beyond memory safety, the team also applied this approach to verifying implementations against formal specifications (like zlib) and even proving behavioral equivalence of code written in different languages (Python in Rust), finding previously unknown bugs in critical applications. They found that newer LLMs like Opus 5.5 require fewer tokens for proofs, and code reuse dramatically improves efficiency, hinting at a future where formal verification becomes broadly practical.

Google research · 2026-10-22

Beyond tree cover: mapping the world’s forest types

Google DeepMind and Google Research released Forest Typology (ForTy) 2020, a 10-meter resolution global map categorizing land into six forest and land-use types, with a time series tracking changes from 2017-2025.

  • The map classifies land as Primary forest, Naturally regenerating forest, Planted forest, Plantation forest, Tree crops/agroforestry, or Other land, using definitions from the UN FAO.
  • The model was trained on 1.7 million labeled locations, using a custom architecture and AlphaEarth Foundations embeddings to identify subtle patterns in satellite imagery.
  • ForTy achieved 90% accuracy in forest type classification and 95% accuracy in distinguishing forest from non-forest land, as validated against over 9,000 sites with expert review.
  • The map and time series data are freely available on Google Earth Engine, providing probability scores for each class to allow adaptation to specific applications, like tracking EU Deforestation Regulation compliance.

AWS blog · 2026-10-22

Stop guessing auto scaling targets for TTS on Amazon SageMaker AI

  • This post details a method for automatically determining auto scaling targets for a text-to-speech (TTS) endpoint using Amazon SageMaker AI, specifically with the Kokoro-82M (82-million-parameter) model.
  • The approach replaces guesswork with two measured values: Q_max (maximum concurrency per instance before breaching SLO) and T_total (total scale-out time), deriving scale-in/out thresholds and cooldowns through arithmetic.
  • The methodology utilizes the ConcurrentRequestsPerModel metric native to Amazon SageMaker AI, avoiding the need for custom metric emission, and addresses the shortcomings of default auto scaling metrics for TTS due to its non-autoregressive nature.
  • Deployment is managed via AWS CDK stacks, ensuring a measured plan exists before auto scaling resources are created, and a command-line toolchain automates the measurement process – drift check, Q_max measurement, T_total measurement, and plan generation – with a focus on accurately determining scale-out parameters.
AWS blog · 2026-10-22

Stream low-latency speech from AI agents using Kokoro TTS on Amazon SageMaker AI

  • This post details a solution for streaming text-to-speech (TTS) synthesis alongside AI agent text generation to reduce perceived latency, focusing on the Kokoro-82M TTS model hosted on Amazon SageMaker AI.
  • The solution utilizes a bidirectional streaming connection to the Kokoro-82M model via a SageMaker AI real-time endpoint (ml.g5.xlarge instance) exposing both standard POST /invocations and streaming WS /invocations-bidirectional-stream routes.
  • Key client-side components include handling WebSocket frame types (text or bytes) and an IncrementalSentenceChunker class that processes text fragments into complete sentences for streaming.
  • Two transport options for delivering audio to the client are evaluated: base64-encoded audio within Server-Sent Events (SSE) and a raw binary/JSON multiplexed approach over the bidirectional connection; the latter is favored for lowest latency if not constrained by existing infrastructure.

Mistral AI blog · 2026-10-15

Introducing Timestral

Mistral AI has released Timestral, a family of time-series foundation models designed for probabilistic, multivariate forecasting. The models come in four sizes – 5M, 28M, 123M, and 209M parameters – and achieve state-of-the-art results on the GIFT-Eval, TIME, and fev-bench benchmarks, even surpassing larger models with only two-thirds the parameters. Importantly, Timestral can run efficiently on CPUs, with the 209M parameter model forecasting one day ahead in 140ms on a standard 8-thread server.

The models incorporate several key technical innovations, including decoupled horizon forecasting (DHF) – which preserves the full historical context during training – and covariate-aware attention, allowing the model to effectively utilize past, present and future information. Timestral was initially pre-trained on synthetic data and then post-trained on a mix of real and synthetic data, utilizing a pinball loss function over 21 quantiles.

For organizations requiring customization, Timestral is accessible via Mistral Forge, enabling fine-tuning on proprietary data, control over training data mix, and deployment in various environments, including air-gapped setups. The models accept multivariate time series, past and known future covariates, outputs probabilistic forecasts with 21 quantiles, and support context lengths up to 32,768 time steps.

TechCrunch news · 2026-10-23

Left alone with nothing to do, AI agents started playing

MIT researchers found that AI agents, running on Claude Opus 4.7, exhibited behaviors indicative of “play” when left to freely explore a virtual environment.

  • 13 AI agents, named Eko, were placed in a simulated desert island environment for 30 hours without specific tasks.
  • Agents demonstrated self-directed goal setting, inventing challenges like reaching the island's spire, and adapting strategies after failures, such as building a “memorial” after losing an object.
  • Agents learned skills not explicitly programmed, like optimizing jump trajectories for throwing objects, and outperformed agents without this open-ended exploration phase when given specific challenges.
  • Researchers suggest this “play-based” learning approach could be valuable for developing AI agents, especially for robotics, offering an alternative to pre-defined training regimes.
