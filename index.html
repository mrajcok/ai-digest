Claude Code in the cloud: a field guide to cloud sessions / claude.dev Blog

Claude Code now supports running sessions on Anthropic-managed virtual machines, called “cloud sessions.” Instead of relying on your local machine’s resources and potentially conflicting with other processes, each task gets a dedicated VM with your repository cloned onto a new branch. This is accessible via claude.ai/code, the Claude mobile app, Desktop app, terminal, and Slack, and supports existing Pro, Max, Team, and Enterprise plans without additional charges (though usage limits apply).

Key benefits include parallel task execution without resource contention, uninterrupted operation even when your laptop is offline, and a clean branch ready for a pull request upon completion. The system handles GitHub authentication via a proxy, never exposing your credentials directly to the VM, and allows for customizable environments with setup scripts and network access controls.

The announcement details several workflows where cloud sessions excel—clearing backlogs, running lengthy tests, offloading compute-intensive tasks, and enhancing security—and provides guidance on connecting to GitHub and configuring environments to maximize effectiveness. A one-time credit of $100 (Pro) or $250 (Max) is available for existing subscribers through October 7th to try the new functionality.

Expanding the Cyber Verification Program

Anthropic has expanded its Cyber Verification Program (CVP), integrating Project Glasswing and the original CVP into a tiered system granting security professionals access to advanced AI models with reduced safeguards. The program now offers three tiers: Defense Access (for general security tasks), Red Team Access (adding authorized penetration testing), and Specialized Access (for critical system testing, currently limited to verified organizations and in collaboration with the US government).

All tiers include access to Claude Opus 5.5, Claude Sonnet 5.5, and Claude Mythos 5.1—and future models—with varying levels of cyber blocks. Testing with CyScenarioBench showed that Defense Access blocked 46 of 50 tasks, while Red Team Access allowed completion of 34 of 50—equivalent to performance with no safeguards. Anthropic reports that through Glasswing, partners identified at least 129,000 verified software vulnerabilities between April and July 2026.

Organizations can apply for CVP access, with varying review times depending on the tier, and data retention is required—though Enterprise Frontier Safeguards will offer a zero-data-retention option later this fall.

Google research · 2026-10-06

EmbeddingGemma 2: an open, lightweight multimodal embedding model

EmbeddingGemma 2 is a new, open-source model for creating multimodal embeddings, unifying text, images, audio, and video into a single vector space.

  • Built on the Gemma 4 architecture with 740 million parameters, it achieves leading scores among sub-1B multimodal embedders on benchmarks like MTEB (Massive Text Embedding Benchmark) Code, MAEB (Massive Audio Embedding Benchmark) and others.
  • The model is modular, allowing developers to use as few as 270M parameters for text-only tasks, with optional encoders for vision (170M) and audio (300M) for full multimodal support.
  • EmbeddingGemma 2 uses Matryoshka Representation Learning (MRL) to reduce storage requirements, allowing dynamic truncation of output vectors to 768, 512, 256, or 128 dimensions, resulting in up to 6x storage reduction.
  • It features an 8K token context window and requires as little as ~191MB RAM (text-only) or ~567MB (full multimodal) on a Google Pixel 11 Pro with quantization, and demonstrates a 9.92-point improvement on code performance (MTEB Code, 68.76 to 78.68).

Mistral AI blog · 2026-10-06

Introducing Mistral Large 4

Mistral AI has released a public preview of Mistral Large 4 (ML4), their largest and most capable model to date. This 1 trillion-parameter, natively multimodal model utilizes 49 billion active parameters and demonstrates competitive performance against leading open-source models, and surpasses other open-weight models, particularly in European and US development. ML4 was trained on 3,800 NVIDIA Grace Blackwell GPUs within Mistral’s European datacenters.

The model excels in areas like coding (achieving 61.7% on DeepSWE v1.1), agentic workflows (59.9% on AutomationBench), and, notably, cybersecurity, where it achieves 82% accuracy on reproducing and patching software vulnerabilities – outperforming closed models often restricted by safety filters. It shows strong multimodal understanding, surpassing even closed models in visual grounding tasks like analyzing satellite imagery and engineering drawings.

ML4’s development included extensive reinforcement learning, processing roughly 33 billion tokens daily. The weights will be released at the end of the month, following red-teaming with cybersecurity experts and authorities. It’s designed for both cloud and on-premise deployment with a particular focus on data sovereignty, with a European deployment operating entirely within European legal frameworks.
