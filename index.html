Anthropic research · 2026-11-23

Working with AI

Anthropic interviewed 66 customers (58 companies) to understand how businesses are adopting AI, finding most value comes from increasing output rather than cost cutting. While layoffs directly attributable to AI were rare, two-thirds of companies reported reduced hiring, with some cutting contracted roles, particularly offshore. The interviews revealed three approaches to AI adoption: top-down automation, which risks resistance and brittle systems; bottom-up experimentation, often led by non-technical experts building niche tools; and broader reorganization.

The most successful deployments involved significant organizational changes – broadening roles, redeploying employees to bottlenecks AI can’t address, and providing infrastructure for non-developers to use AI and access data. Many companies are using AI agents to automate tasks like coding, document processing, and customer service. Eighty percent of new software built with AI automated existing manual work; the remaining 20% replaced existing vendor software.

Companies face challenges in integrating AI, including expert resistance, tasks unsuitable for AI acceleration, and the need to update workflows as models improve. A key finding is that simply providing AI tools isn't enough; maximizing value requires deliberate reorganization and a focus on augmenting, not simply replacing, human expertise.

OpenAI news · 2026-11-24

How iFood scales coding agents across 15,000 repositories

iFood has implemented the Remote Agents Platform, an internal API enabling coding agent tasks across its 15,000 code repositories. The platform utilizes a REST API to submit prompts, executes tasks in isolated Ubuntu sandboxes with common toolchains (Python, Java, etc.), and delivers results as merge requests. Crucially, the platform leverages OpenAI’s GPT-5.6 Luna due to its balance of intelligence, efficiency, and speed, averaging US$0.04 per run.

The initial major application is an internal security platform which saw a greater than 2x increase in the number of vulnerabilities fixed after migrating to the new platform. The platform’s design was inspired by OpenAI’s APIs, emphasizing asynchronous execution to free developers from routine monitoring. To date, the platform has completed over 25,000 runs, consuming 27 billion tokens, and relies on OpenAI's Structured Outputs to ensure consistently formatted results.

iFood emphasizes that the primary challenge at scale isn’t identifying valuable automation opportunities, but building reliable execution infrastructure. They plan to expand the platform to additional use cases, with cost-per-task as a key scaling factor.

Google research · 2026-11-23

Finding faster quantum algorithms with agents and formal verification

Gemini 4 agent teams, combined with formal verification using the Lean library, achieved improvements in quantum algorithms for fusion energy, chemistry, and enzyme simulation.

  • Agent teams improved a quantum circuit for inertial confinement fusion, reducing the required computational cost by 11.8× and lowering memory requirements from 5,650 to 4,338 error-corrected qubits.
  • For a light-sensitive molecule, the agents made quantum simulation 8× cheaper by optimizing particle tracking.
  • Improvements to Cytochrome P450 simulation resulted in a 2.5× speedup and reduced memory from 481 to 333 qubits.
  • A 2.57x speedup was achieved for a specific implementation of Grover's algorithm, and a 290x speedup for arcsin, a routine used in many quantum algorithms.

The Lean library, problem specifications, and verified solutions are open-sourced on GitHub.
