Anthropic blog · 2026-09-28

Giving companies more control over their AI agents, with NVIDIA | Claude by Anthropic

Anthropic and NVIDIA have collaborated to enhance AI agent security through a layered approach. Claude Managed Agents provide a secure environment for running agents, handling credentials in a vault inaccessible to the agent itself, and offering audit trails alongside integration with existing access controls. These agents support long-running, autonomous sessions and orchestration of multiple agents in parallel.

Complementing this, NVIDIA’s open-source OpenShell software acts as a runtime environment that governs agent behavior, blocking actions unless explicitly permitted by defined rules. OpenShell verifies access to tools, files, network connections, and data, logging all decisions. The system also includes a policy prover that mathematically confirms agent access limitations based on configured rules. Both Claude Managed Agents and NVIDIA OpenShell are available now, with OpenShell licensed under Apache 2.0 and hosted on GitHub.

Build plugins for Claude with the directory submission portal | Claude by Anthropic

Anthropic has launched a directory submission portal for developers to publish plugins for Claude. These plugins can incorporate MCP connectors, Agent Skills, or both, and are intended to extend Claude’s functionality. Anthropic research · 2026-09-25

Claude computes a nine-loop amplitude in N=4 super-Yang-Mills

Anthropic’s Claude model has computed the nine-loop amplitude for N=4 super Yang-Mills, a complex calculation in theoretical particle physics previously considered computationally challenging. This was achieved using the Claude Science platform (built on the Claude LLM), specifically version Fable 5.1, and required approximately $100 in compute costs—96 CPUs running for a week. The calculation was performed using the Python programming language with the SymPy package, employing both the original bootstrap method and an indirect form-factor approach.

This result surpasses prior work which had reached eight loops with significant effort; the method leverages a “bootstrap” technique for scattering amplitudes. Notably, a team in China, led by Song He, independently obtained a similar result using GPT-6 assisted methods around the same time.

The achievement demonstrates Claude’s ability to handle complex scientific computation autonomously with minimal oversight, and suggests that there may be more readily solvable problems in the field than previously assumed. While this doesn’t represent a fundamental breakthrough in methodology, it showcases AI’s increasing capacity to execute established techniques efficiently.

AWS blog · 2026-09-28

Automating Amazon Textract adapter lifecycle management across accounts

  • Amazon Textract adapter lifecycle management is automated across accounts using AWS Systems Manager Parameter Store to decouple adapter management from application logic, enabling updates with zero downtime.
  • The solution utilizes a multi-stage processing pipeline—ingestion, pre-classification (using DetectDocumentText for version identification), adapter selection from Parameter Store, processing via AnalyzeDocument/StartDocumentAnalysis, and results delivery—with options for network isolation with AWS PrivateLink.
  • Two adapter promotion strategies are available: a standard cross-account copy via AWS Support (suitable for few adapters) and a centralized hub account approach reducing operational overhead for many adapters.
  • Infrastructure deployment and management are supported via AWS CloudFormation and Terraform (version 1.4+), leveraging the terraform_data resource as a temporary solution for adapter creation until native Terraform provider support is added, requiring specific IAM permissions detailed in the post.

Mistral AI blog · 2026-09-10

Cloudera and Mistral Partner to Bring Specialized, Sovereign Intelligence to Enterprise Data

Mistral AI and Cloudera have partnered to offer enterprises greater control over their AI deployments. The core offering focuses on enabling inference and custom model training directly within a customer’s existing data environment—whether on-premise, in a private cloud, public cloud, or even air-gapped systems. This addresses the need for “sovereign AI,” where data, compute, and operations remain fully under customer control.

Mistral’s models will integrate with Cloudera’s hybrid data platform, allowing organizations to run AI without transferring sensitive data. Crucially, enterprises can leverage decades of proprietary data—such as loan decisions or production telemetry—to train customized AI models. This process generates AI tailored to specific business needs, with the company retaining full ownership of both the data and the resulting intelligence.

The partnership emphasizes a shift from relying on generic, rented AI models to owning specialized intelligence built on an organization’s unique data assets. Cloudera manages 30 exabytes of customer data, providing a substantial base for these customized AI applications.

Ars Technica news · 2026-09-28

Microsoft goes quiet after church groups ask for 1% of data center costs

Microsoft is facing pressure from community groups in Indiana to invest more substantially in local services related to its new data center.

  • We Make Indiana proposed a “Fair Share Agreement” where Microsoft would contribute a percentage of its data center costs to a community fund, initially suggesting 1-2% (potentially up to 10%), which could total $30-$40 million annually at 1%.
  • The proposal followed concerns that Microsoft’s initial commitments of up to $1 million in one-time donations were insufficient given the scale of the project and associated tax breaks, with the group arguing this appeared as "buying silence."
  • Microsoft has paused substantive discussions, stating it is still gathering community input, despite previously promising to be a "good neighbor."
  • A parallel effort in Pennsylvania has resulted in the Data Center Fair Share Act, which would legally require data center developers to contribute at least 10% of project costs to community benefit funds.
