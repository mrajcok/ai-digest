Improving Fable 5 Safeguards

Anthropic has released updates to Claude Fable 5’s biology safeguards, substantially reducing false positives—instances where the system unnecessarily switches to the less capable Opus 5 model. Testing indicates an 85% reduction in biology-related fallbacks across Anthropic’s product surfaces including Claude.ai, Cowork, Code and the platform. This means Fable 5 will be able to handle a wider range of biology-related tasks, like interpreting lab results and learning about biological concepts.

These improvements stem from a re-written classifier constitution, coupled with updated training data and expert feedback, aiming to better distinguish between benign and harmful biology queries. While Fable 5 will still block requests deemed “dual-use”—particularly in areas like virology, toxicology, and molecular design—the update intends to allow more legitimate biological inquiry. Anthropic reports overall fallbacks are expected to decrease by 67% on Claude.ai, 55% on Cowork, 17% on Claude Code, and 7% on the Claude Platform.

Anthropic emphasizes the potential for both positive impact and misuse in biology, making caution paramount and outlining ongoing commitments to develop trusted access pathways for responsible frontier biology research.

Anthropic blog · 2026-08-06

Self-hosted environments for Claude Code | Claude by Anthropic

Anthropic now offers self-hosted environments for running Claude Code sessions, currently in public beta for Claude Team and Enterprise plan customers (excluding those using Zero Data Residency, or ZDR). This allows organizations to execute Claude Code within their own infrastructure, maintaining control over network access, customization, and compliance. Sessions can be initiated from web, mobile, desktop, or existing routines.

The core feature involves deploying “runners” – long-lived processes that execute Claude Code sessions. These come in two modes: "fixed," maintaining a constant number of runners, and “on-demand,” which dynamically scales runner capacity based on queued sessions. Importantly, while prompts, responses, and tool results are sent to Anthropic for inference and transcript storage, all repository checkouts, build artifacts, and secrets remain within the customer's infrastructure. This differs from the Remote Control feature, which ties sessions to a specific user’s machine and terminates when that machine stops running.

Organizations considering self-hosting should anticipate the need for dedicated platform or developer experience engineering teams to manage setup, maintenance, and runner image updates. Anthropic provides documentation and requests feedback via GitHub or account teams.

Google research · 2026-08-06

WeatherNext: AI model achieves breakthrough in forecasting cyclones

WeatherNext, an AI model from Google DeepMind and Google Research, achieves state-of-the-art accuracy in cyclone track, intensity, and wind structure forecasting, providing an average of 24 hours more lead time than previous models.

  • The model, WeatherNext Cyclones, leverages Functional Generative Networks (FGNs) to efficiently generate 1,000-member ensembles of predictions, capturing uncertainty and rare events.
  • It was co-trained on nearly 20 terabytes of global atmospheric data and the IBTrACS database containing nearly 5,000 historical storms to learn complex atmospheric patterns.
  • WeatherNext Cyclones performs well at a relatively coarse resolution of 28x28km, challenging the assumption that high-resolution data is essential for accurate intensity forecasts.
  • Google is open sourcing WeatherNext 2 and WeatherNext Cyclones, along with code and model weights, to empower the research community and improve global weather forecasting; a smaller version, WeatherNext 2-mini, is available in a public Colab notebook.

Mistral AI blog · 2026-08-04

Introducing Shieldstral.

Mistral AI has released Shieldstral, a 3 billion parameter open-weights model designed for multimodal safety classification. The core innovation is framing content moderation as a question-answering task, allowing users to define safety policies in plain language at inference time without requiring model retraining. Shieldstral accepts a structured input consisting of an instruction, a yes/no query representing the safety policy, and the content to be evaluated (text, image, or both), then outputs a calibrated safety score.

The model is designed to rival the performance of models up to seven times its size on text safety and achieves state-of-the-art results on multimodal moderation tasks. It was trained on a combination of real and synthetically generated data and requires only a single 16GB NVIDIA GPU for operation. Shieldstral is available under the Apache 2.0 license and was created utilizing Mistral’s Forge platform.

Key to Shieldstral's performance is its approach to data handling: unifying diverse datasets, teaching the model to discriminate between similar policies rather than memorizing labels, incorporating image data, and combining multiple fine-tuned checkpoints.

Mistral AI blog · 2026-07-09

Your Prompts and Skills need a system of record.

Mistral AI’s Studio now offers a system of record for managing AI prompts and skills, addressing the common enterprise problem of scattered and unmanaged instructions. This feature treats prompts as production assets, providing version control, ownership, and audit logs to ensure AI behavior is governed and traceable. Every prompt or skill receives an immutable version, a designated owner, and can be labeled for classification (e.g., “Production” vs. “Staging”).

The system aims to accelerate iteration by allowing quick testing of changes without requiring full CI/CD pipelines, while still maintaining enterprise-level controls for deployment. Domain experts can directly improve production instructions, triggering existing CI/CD processes via the Mistral SDK. Importantly, Studio connects these governed assets to runtime behavior through observability, lineage, and telemetry, tracing outputs back to specific versions and usage data.

This differs from standalone prompt catalogs by providing a closed-loop system where behavior is defined, monitored, and improved against a single source of truth, helping organizations maintain compliance and reduce risk related to ungoverned AI instructions. The feature is currently available to Mistral Studio customers.

Mistral AI blog · 2026-07-08

Introducing Robostral Navigate

Mistral AI has introduced Robostral Navigate, an 8B parameter model designed for robot navigation using only a single RGB camera. Unlike many existing solutions that require depth sensors or multiple cameras, Navigate achieves a 76.6% success rate on unseen R2R-CE (Room-to-Room in Continuous Environments) benchmarks – surpassing existing single and multi-sensor approaches by 9.7 and 4.5 points respectively.

The model works by predicting target locations using "pointing" – inferring image coordinates and desired orientation – and falls back to metric displacements when the target is out of view. Training leveraged 2.4 million simulated trajectories across 350k scenes, using a token-efficient prefix-caching method that reduced training time by a factor of 22x.

Further performance gains (a 3.2% improvement in success rate) were achieved via online reinforcement learning with the CISPO algorithm. Robostral Navigate has demonstrated successful operation on various robot types—wheeled, legged, and flying—and is notable for being built entirely in-house, not relying on existing open-source visual-language models.
